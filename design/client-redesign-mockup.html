UI and video

Only these four values are changed; comments, other keys and line endings in settings.cfg stay as they are.

TTF resolution 16–48

Glyph atlas resolution: higher makes letters crisper at a large font size and costs video memory — this is what removes the blurry stock text.

Font size 8–32

Base interface text size — the in-game «text size». Keep it in step with TTF resolution: a large font on a small atlas looks rough.

Scaling factor 0.5–4

Scale of menus and HUD: 1.00 is the original size, 1.50–2.00 is comfortable on 1440p and 4K.

Framerate limit 0–360

0 means no limit. 60 is enough for Morrowind; on a 120–144 Hz display use 120 or 144 to avoid a tearing cap.

settings.cfg appears after the first game start. Until then the row in Installation shows «Launch the game once».

Как это ложится на Fyne и что меняется в коде
  • Rail — `container.NewVBox` из `widget.Button` с `Importance = High` у активного; Fyne не умеет стилизовать `AppTabs`, поэтому свой список. Пять разделов: Play · Installation · OpenMW-CS · Diagnostics · About. Тема — три `widget.Button` в шапке (System/Dark/Light, активная с `HighImportance`), без выпадающего меню.
  • Play — без изменений: `style.Card`, `ui.go:158`. Кнопка «Add server» остаётся только здесь: глобальная «＋» из шапки удаляется.
  • Installation — новый `screen_install.go`: строки = `style.Card` + `container.NewBorder(nil,nil,nil,container.NewHBox(buttons...), text)`. Состояния уже есть в `app`: `TES3MPState`, `FontsState`, `LocalizationState`, `ModsState`, `CheckMorrowind`; добавляется `ClientSettingsState` (settings.cfg) и `EditorState`. Advanced = `widget.Accordion` только с work dir, Proton и строкой Client profile; папки, лог и отчёт уезжают в Diagnostics. Внизу — только Uninstall.
  • OpenMW-CS — отдельный `screen_cs.go`: `app.OpenMWCS` уже есть и сам требует установленных модов (`ErrModsNotInstalled`), бинарник — `launcher.OpenMWCSExecutable`, «открыть папку» — по образцу `openFolderCommand` (`logs.go:22`); добавляется только статус-чек `os.Stat(tes3mp.Dir/openmw-cs.exe)`.
  • UI and video — новый пакет `internal/openmwcfg` (INI с сохранением порядка/комментариев/CRLF), `app.ClientSettings/UpdateClientSettings`, бэкап `settings.cfg.bak-<ts>`. Подписи полей берут диапазоны из констант `openmwcfg` (`MinTTFResolution..MaxTTFResolution` и т.д.) и дефолты из `Default*`, поэтому UI и валидация не могут разойтись; пояснения — ключи `install.uivideo.*_hint`, общего блока «что меняется в файле» хватает одного.
  • Diagnostics — новый `screen_diagnostics.go`: хвост лога из `app.ReadLogTail` (`logs.go` уже умеет), кнопки `copyReport` / `openLogFolder` / `openFolder`, те же пути, что были в Installation → Advanced → Folders. Ни меню, ни Installation больше их не дублируют.
  • About — новый `screen_about.go`: версия клиента и TES3MP, лицензия, ссылка на проект и единственный селектор Interface language (`app.UpdateSettings` + `i18n.Resolve`). Тема сюда не дублируется — она в шапке.
  • Меню «⋯» больше нет — `appMenu`, `headerActions`, `KeyCommonMenu` и `KeyRailMenuNote` удаляются: тема → шапка, язык интерфейса → About, язык игры → Installation, лог/отчёт/папки → Diagnostics, About → вкладка. `showSettings` (`dialogs.go:156`) остаётся удалённым, пути Morrowind / work dir / Proton — только Installation → Advanced.
  • Язык игры — `language_wizard.go` остаётся диалогом одного шага (пак-строка, вариант «только текст / текст + озвучка», статус, `[Установить] [Удалить] [Отмена]`), но вход теперь один: строка Installation → Game language. Пункт «⋯ → Язык игры…» и его i18n-ключ удаляются.
  • Шрифты — `internal/fonts` получает каталог наборов (`Set` в `Options`), в конфиге `font_set` вместо неиспользуемого `skip_fonts`. Мастер только сохраняет выбор: никакой загрузки по клику в шаге 3. После `CompleteSetup` шелл запускает `InstallFonts` в горутине и рисует прогресс/«Cancel»/«Retry» прямо в строке Fonts; диалог Fonts тоже качает только по явной кнопке Download, а не по выбору радио.
  • Мастер — `wizard.go`: 4 шага (Morrowind → TES3MP → Fonts → UI and video), `wizardReady` и `KeyWizardReady*`/`KeyWizardSummary` удаляются, на шаге 4 кнопка `Finish`; `setup_complete` пишется там же. У Fonts одна кнопка Next: развилки «Next / Install fonts and continue» больше нет. Если Morrowind уже настроен, мастер по-прежнему стартует с шага 2.
  • Удаление — новый `app.Uninstall(scope)`; удаление только внутри workDir/cacheDir/configDir, без прохода по симлинкам.
