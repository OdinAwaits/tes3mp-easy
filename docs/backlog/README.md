Отложенные задачи клиента и сервера. Одна запись — один файл в этой папке:
симптом, причины с кодом, что делать и как проверять. Здесь только индекс.

Статусы: `новое` — не брались, `отложено` — разобрано, ждём триггера,
`в работе`, `сделано`. Записи не контракт: если расходятся с
[`v2/03-contracts.md`](../v2/03-contracts.md), прав контракт.
