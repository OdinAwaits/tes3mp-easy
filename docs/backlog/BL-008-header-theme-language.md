# BL-008. Шапка: тема и язык рядом, без перерисовки окна

**Статус:** новое (28.10.2026), не начато. Включает BL-011 («Язык интерфейса — в
шапку, рядом с темой»).

**Симптом.**

- Тема переключается тремя текстовыми кнопками в правом верхнем углу: «Как в
  системе», «Тёмная», «Светлая». Шапка — одна строка и не переносится: группа
  стоит справа и своей шириной отжимает бренд слева, а при нехватке ширины бренд
  и группа перекрываются (минимальный размер окна не задан, есть только
  `Resize(1000, 700)`). Русские подписи длиннее английских, поэтому при смене
  языка группа меняет ширину и шапка прыгает. Сама группа не подписана —
  непонятно, что это переключатель темы. После клика окно перерисовывается
  целиком: сбрасывается прокрутка экрана и фокус.
- Язык интерфейса меняется только на информационном экране «О клиенте»:
  выпадающий список шириной 160 px с подписью и пояснением. Переключить язык
  можно только уйдя с текущего экрана. Пояснение «Язык игры остаётся на вкладке
  «Установка»» рассказывает про соседнюю настройку вместо самой.

**Причина.**

- `themeSwitch` (`internal/ui/ui.go:214-234`) собирает три `widget.NewButton` в
  `container.NewHBox` и отдаёт их как правую часть шапки (`container.NewBorder`,
  `internal/ui/ui.go:92`). Ни фиксированной ширины, ни переноса, ни подписи у
  группы нет; `KeySettingsTheme` («Тема») в каталоге есть
  (`internal/i18n/catalog.go:179,499,819`), но в UI не используется.
- Активный режим получает `HighImportance` (`themeOptionImportance`,
  `internal/ui/ui.go:238-243`), остальные — `MediumImportance`, то есть по
  контрасту почти невидимы (BL-007). Визуально это одна янтарная кнопка с двумя
  подписями рядом, а не переключатель на три состояния.
- `setTheme` (`internal/ui/ui.go:246-255`) сохраняет настройку и вызывает
  `render()` (`internal/ui/ui.go:85-110`), а тот строит окно заново через
  `SetContent`, заново применяет тему и пересоздаёт `s.body` со `VScroll` —
  поэтому прокрутка и фокус теряются на каждом переключении.
- `aboutScreen` создаёт `widget.NewSelect` из `interfaceLanguageLabels`, ставит
  `SetSelected(DisplayName(...))`, оборачивает в `NewGridWrap(fyne.NewSize(160, …))`
  и кладёт в `aboutLine` — `internal/ui/screen_about.go:24-40`. В шапке
  единственный контрол — `headerActions`, который возвращает только
  `themeSwitch` (`internal/ui/ui.go:208-210`). Ключи
  `about.interface_language` и `.hint` (`internal/i18n/catalog.go:303-304`,
  `625-626`, `945-946`) привязаны к About, а комментарий у экрана называет его
  «the only interface language selector» (`screen_about.go:15-17`).
- В документации выбор языка описан и в меню «⋯», и в About
  (`docs/v2/06-client.md:551,561`); меню в коде нет.
- В Fyne нет иконок «солнце/луна»: в `theme` есть только `ColorAchromaticIcon`,
  `ColorChromaticIcon`, `VisibilityIcon`/`VisibilityOffIcon`. Своих SVG клиент не
  встраивает: `//go:embed` есть только у панели (`internal/panel/static.go:18`).

**Что делать.**

1. Собрать шапку как `container.NewHBox(languageSwitch(tr), themeSwitch(tr))` в
   `headerActions`: одинаковые высоты и отступы, фиксированная ширина обоих
   контролов, без подписей-пояснений. Это снимает и перенос, и прыжок ширины при
   смене языка, и перекрытие бренда.
2. Тема — `widget.NewSelect` с тремя режимами (`container.NewGridWrap` ~150 px,
   подсказка `KeySettingsTheme`): видны все состояния, включая `system`, ширина
   не зависит от языка и от длины подписи. Подписи режимов уже есть —
   `KeyThemeSystem/Dark/Light` (`internal/i18n/catalog.go:181-183`). Паттерн
   списка уже используется (`screen_about.go:24-37`). Альтернатива — тоггл
   «светлая ⇄ тёмная» в один клик, но тогда `system` придётся унести в About, а
   About по п. 5 остаётся без настроек; поэтому для этой пары выбираем `Select`.
3. Язык — одна кнопка-тоггл с названием языка, на который переключаемся
   (`i18n.DisplayName(target)`): при двух языках это честнее списка, новых
   ключей не нужно, названия уже локализованы. Если языков станет больше —
   заменить на такой же `Select`.
4. `setTheme` не должен перерисовывать окно целиком: достаточно
   `Settings().SetTheme` плюс обновления состояния контрола. `render()`
   остаётся только для смены языка — там меняются все строки; шапка
   пересоздаётся с тем же выбором.
5. Убрать строку языка из About, удалить `KeyAboutInterfaceLanguage*` из обоих
   каталогов, поправить комментарий экрана (`screen_about.go:15-17`) и
   документацию (`docs/v2/06-client.md:74`, `:551`, `:561`). Описание темы в
   документации — на `Select` из трёх режимов.

**Как проверять.** Окно 900, 1000 и 1200 px на русском и английском: шапка не
переносится, бренд не обрезан, ширина группы не меняется при смене языка.
Переключение темы: применяется сразу, `theme` в `config.json` обновляется,
прокрутка и фокус остаются на месте, после перезапуска тема та же.
Переключение языка с любого экрана: строки шапки, подвала и тела меняются сразу,
выбор сохраняется после перезапуска, About не содержит селектора языка. Тесты:
вместо `TestThemeOptionImportance` (`internal/ui/ui_test.go:26-33`) — проверка
состояния темы по `style.Mode` и выбранного языка хелпером в духе
`TestThemeLabels` (`ui_test.go:99-110`); драйвер Fyne (`testShell`,
`internal/ui/screen_test.go:18`) — в шапке нет трёх кнопок темы, в About нет
`*widget.Select` языка.
