# BL-021. Превью шрифтов: три гарнитуры набора, размер и докачка файлов

**Статус:** сделано (28.10.2026). Продолжение BL-012: образец теперь показывает
все три файла набора, связан с полями `font size` / `scaling factor` и докачивает
незагруженные файлы в кеш вместо тихой подмены шрифтом лаунчера.

Итог: `fontPreview` (`internal/ui/font_preview.go`) — три строки (интерфейс,
Daedric, консоль) с образцом из файла своего слота и подписью-арифметикой
`16 × 1.25 = 20 px`; кегль берётся из `uiVideoForm` по `OnChanged`
(`internal/ui/dialog_uivideo.go`), в диалоге Fonts — базовые 16 px без подписи;
сверху образец ограничен 32 px с честной подписью «показано 32 из 128». Новый
`fonts.EnsureCached` (`internal/fonts/fonts.go`) и
`app.Service.EnsureFontsCached` + `FontCacheDir` кладут три файла набора в
`cache/fonts/` без записи `Fonts/`, `openmw.cfg` и `openmw_font.xml`; установка
после Finish берёт их из кеша. Фолбэк на шрифт темы остался только при ошибке
загрузки — с текстом ошибки и кнопкой **Retry**. Документация: `docs/v2/06-client.md`
§9. Защита: `TestEnsureCachedFillsCacheWithoutInstalling`,
`TestEnsureCachedWarnsWhenAFontFails`, `TestFontPreviewShowsEverySlotFile`,
`TestFontPreviewDownloadsMissingSet`, `TestFontPreviewNamesADownloadFailure`,
`TestFontPreviewSizeFollowsSettings`.

**Симптом.**

- В наборе три файла (интерфейс, Daedric, консоль), а образец — одна строка:
  serif и моноширинный вариант выбрать вслепую, хотя консоль и подписи свитков
  видит каждый игрок.
- Рядом в том же шаге стоят `font size` и `scaling factor`, но образец всегда
  одного кегля: нельзя понять, как будет выглядеть текст при своих настройках,
  и придётся запускать игру, чтобы это увидеть.
- Пока набор не скачан, образец набран шрифтом лаунчера: выбираешь Roboto,
  видишь тот же Arial — превью не отвечает на вопрос «как это будет выглядеть»,
  а после Finish начертание меняется. Подмены не видно: пометки, что это не
  выбранный шрифт, нет.
- Про превью в документации сказано «образец берёт установленный файл первого
  слота», то есть ограничение зафиксировано как контракт.

**Причина.**

- `fontPreview` (`internal/ui/font_preview.go:25-…)` держит один `canvas.Text`
  с `TextSize = 22` (`:36-38`), `selectSet` (`:51-61`) подставляет
  `Assets[0]`, `face` (`:63-75`) читает только первый файл — комментарий там
  прямо говорит «Only the first asset is used».
- Фолбэк на шрифт темы — это `selectSet` (`:51-61`): при ошибке чтения он берёт
  `theme.TextFont()`, а `face` (`:63-75`) возвращает `false` на любой ошибке, в
  том числе на «файла ещё нет».
- Скачивание стартует только после Finish (`startFontDownload`,
  `internal/ui/font_download.go:58`), а `selectFontSet`
  (`internal/ui/wizard.go:230-244`) сохраняет лишь `font_set`. До этого `Fonts/`
  пуст, поэтому превью и уходит в фолбэк.
- Слоты и их назначение описаны в `internal/fonts/config.go:47-58`
  (`Magic Cards` → `assets[0].Name`, `Daedric` → `assets[1].Name`, `MonoFont` →
  `assets[2].Name`), то есть источник для трёх строк уже есть.
- Поля `settings.cfg` живут в том же шаге (`uiVideoForm`,
  `internal/ui/dialog_uivideo.go:37-156`), но с превью не связаны: `fontSize` и
  `scaling` пишутся только в форму, `OnChanged` у полей не подписан.
- Диапазоны и значения по умолчанию: `FontSize` 8–32 (по умолчанию 16),
  `ScalingFactor` 0.5–4 (по умолчанию 1) — `internal/openmwcfg/openmwcfg.go:47-61`.
- Тест `TestFontPreviewFollowsTheInstalledFile` (`internal/ui/ui_test.go:595-624`)
  закрепляет и один источник, и фолбэк («keeps the launcher font instead of an
  empty sample»), поэтому расширение превью его сломает.

**Что делать.**

1. Одно превью на три строки, размер — прямо в нём: у каждой строки мелкая
   подпись слота («Интерфейс» / `Assets[0]`, «Daedric» / `Assets[1]`,
   «Консоль» / `Assets[2]`) и образец в файле этого слота, набранный
   эффективным кеглем `FontSize × ScalingFactor`. Отдельного блока размера нет:
   тип и размер видны одновременно, один и тот же кегль применяется ко всем
   трём строкам. Подписи слотов — новые ключи i18n в обоих языках.
2. Файлы докачивать, а не подменять: если файла слота нет ни в `Fonts/`, ни в
   `cache/fonts/`, превью запускает фоновую загрузку выбранного набора в кеш —
   новый `fonts.EnsureCached(ctx, Options)` с теми же `download.Fetch`, SHA256,
   `Attempts` и `Progress` (`internal/fonts/fonts.go:106-188`), но без записи
   `openmw.cfg`/`openmw_font.xml`. Установку по-прежнему делает Finish/`Install`,
   и она возьмёт файлы из кеша без сети. Шрифт темы остаётся только на случай
   ошибки загрузки — с пометкой и Retry, а не молчаливой подменой.
   Альтернатива, если новый API не нужен: на шаге звать полную установку набора
   при выборе (как `startFontDownload`), но тогда ломается контракт «конфиг
   пишется после Finish» из BL-012.
3. Пока загрузка идёт, строка слота показывает «Загрузка…», а образец остаётся
   шрифтом темы — подмена названа, а не выдана за выбранный набор. Байтовый
   прогресс в превью не нужен: это три файла набора, прогресс установки уже есть
   в строке Fonts. Кеш держит один набор
   (`pruneFontCache`, `internal/fonts/fonts.go:331-349`), поэтому докачка — это
   три файла выбранного набора, а не весь каталог; `selectFontSet` уже сохранил
   выбор, так что кеш и `font_set` не расходятся.
4. Строка-подпись под превью `16 × 1.25 = 20 px` (кегль, множитель, факт) —
   единственное место, где размер назван числом. Пересчитывается по `OnChanged`
   полей `fontSize`/`scaling` из `uiVideoForm`; невалидное значение превью не
   меняет — ошибку показывает существующий валидатор формы. `ttf resolution` в
   размер не входит: он меняет разрешение текстуры шрифта, а не кегль.
5. Кегль в превью ограничить сверху: `canvas.Text` не переносит и не обрезает
   строку, поэтому 32 × 4 = 128 px вылезет из колонки. Считать
   `min(effective, предел колонки)` (ориентир — 32 px при вёрстке из BL-020) и
   писать в подписи фактическое значение, если оно урезано: «показано 32 из
   128». Урезание — только для образца, сохранённое значение не меняется.
6. `fontPreview` получает `setScaling(fontSize int, factor float64)` (или
   `setSize`), которую вызывают поля формы; в диалоге Installation → Fonts
   полей нет, поэтому там те же три строки показываются базовым кеглем (16 px),
   а подпись размера скрыта. Докачка файлов нужна и там — иначе диалог тоже
   показывает чужой шрифт.
7. Обновить `docs/v2/06-client.md` §9 (`:450-457`): убрать фразу «пока файла
   нет, он набран шрифтом лаунчера» и описать один образец на три слота,
   кегль из `font size` × `scaling factor` и докачку файлов в кеш.

**Как проверять.** Чистый конфиг, шаг «Шрифты и интерфейс»: выбор набора
запускает докачку трёх файлов в кеш, строки заполняются по мере готовности;
ни одна строка не набрана шрифтом темы без пометки. После Finish установка не
ходит в сеть (файлы уже в кеше). Сеть выключена: строки показывают ошибку и
шрифт темы с пометкой, Retry повторяет загрузку. Смена набора: три строки
меняются на три файла этого набора. Правка `font size` 16 → 24 и
`scaling factor` 1 → 1.25: образец растёт (24 × 1.25 = 30), при недопустимом
значении не меняется и форма не сохраняется; `32 × 4` даёт подпись «показано 32
из 128». В диалоге Fonts — те же три строки базовым кеглем, без подписи размера,
и докачка при смене набора. Тесты: fake HTTP-сервер и temp-каталоги;
`TestEnsureCachedFillsCacheWithoutInstalling` (три файла в кеше, `Fonts/` пуст,
следующий `Install` без сети), `TestEnsureCachedWarnsWhenAFontFails`,
`TestFontPreviewShowsEverySlotFile` (три источника, каждая строка — свой файл),
`TestFontPreviewDownloadsMissingSet` (запрос ушёл, файл в кеше, `FontSource` —
имя файла слота, повтор не ходит в сеть), `TestFontPreviewNamesADownloadFailure`
(шрифт темы, текст ошибки, Retry, без тихого фолбэка),
`TestFontPreviewSizeFollowsSettings` (16×1.0 = 16, 16×1.25 = 20, урезание
сверху, невалидное значение не меняет образец).
