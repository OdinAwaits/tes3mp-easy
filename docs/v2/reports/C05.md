# C05 — state и `current.txt`

- Сделано: `ValidateState`/`ValidateStateFile`/`ValidateStateReader`, `ParseCurrent`, `ReadCurrentFile`, `VerifyStateMods`.
- Layout: только `players/` и `world/{cell,world,map,recordstore,custom}`, без плоских и вложенных путей; обязательны `requiredDataFiles.json` и `current.txt`.
- `current.txt`: ровно `<sha256> <filename>\n`, LF, 64 lowercase hex, UTC-имя `mods-*`/`mods-init-*` с суффиксом `-01`.
- Целевой архив обязан существовать в `backups/mods/`, совпадать с его `current.txt` и иметь записанный sha256.
- Ошибки формата, отсутствующие каталоги/метаданные, чужой current и битый sha256 дают `ErrInvalid`.
- Проверено: `go test`, `go test -race`, `go vet`, `gofmt`, сборка Linux/Windows.
- Ограничение: CLI-команды и staging/rollback — W05.
- Дальше: C06 — retention и имена архивов.
