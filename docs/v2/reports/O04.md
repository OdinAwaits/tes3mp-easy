  `cgroup`, `filesystems`, `budgets`, `current`, `datafiles`, `archives`,
  `configs`, `cleanup`, `journald-config`. Порядок проверок стабилен.

  `.part`/`.old-*`/`.staging`/lock-файлы, кэпы journald.

  argv `systemctl show <unit> --property=MemoryHigh,MemoryMax`.

  `go test -race ./... -count=1`, `go test ./test/docs`, `git diff --check`.

  `systemctl`/`journalctl`/`ldconfig`/`ldd`; root не меняется, unavailable
  systemd не вызывает journald/cgroup.
- Ограничение: real-host smoke на VM Debian 12/Ubuntu 24.04 с настоящими
