# P04 — Публичный API и страницы

- Сделано: `internal/panel/public.go` и шаблоны `home.html`/`backups.html`; `GET /` показывает имя, порт, статус, текущий mod-архив и ссылки.
- `GET /backups` вызывает `ops backups list` для `state`/`mods`, проверяет `limit=1..500` и `before`, строит `next_before` и группирует отображение по дням/ISO-неделям/месяцам.
- Скачивания `/backups/{mods,state}/<name>` отдают только регулярный `.tar.gz`; проверяются `path.Base`, symlink и каталоги, есть `Content-Type`/`Content-Disposition`.
- `GET /api/v1/server` отдаёт точную JSON-схему, `no-store`, `mods_sha256` или `null`; systemd-сбой даёт `503 service_unavailable`, а не `running`.
- `GET /api/v1/mods/current` и `/archive` читают `current.txt`, дают `404 no_mods`, `ETag`/`304`, `application/gzip` и `Content-Length`.
- Скачивания и архив модов делят лимит 60/мин на IP: `429` + `Retry-After`, для API — `rate_limited`.
- Проверено: `go test ./... -count=1`, `go test -race ./internal/panel`, `go vet`, `go build`, `gofmt`, `git diff --check`; добавлены public-тесты, проверки traversal/symlink/каталогов и лимитера.
- Ограничение: публичные бэкапы без авторизации по решению MVP; sha256 текущего архива не пересчитывается на каждый запрос. Дальше: P05 — админка, статус/логи/моды/state/конфиги и upload.
