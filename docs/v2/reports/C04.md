# C04 — валидация mods-архивов

- Сделано: `ValidateMods`/`ValidateModsFile`/`ValidateModsReader` и `ParseRequiredDataFiles` в `internal/archive`.
- Проверяется layout `plugins/`/`scripts/`, JSON только в `plugins/`, расширения и имена скриптов, отсутствие вложенных каталогов.
- CRC32 IEEE считается потоково; JSON ограничен 8 MiB; плагины в память не загружаются.
- `requiredDataFiles.json`: порядок базовых ESM, уникальные имена без учёта регистра, `0x` + 8 uppercase hex.
- Базовые ESM в архиве, missing/extra плагины и несовпадение CRC дают `ErrInvalid` (`archive_invalid`); опасные пути — `pathguard.ErrUnsafePath`.
- Проверено: `go test`, `go test -race`, `go vet`, `gofmt`, `git diff --check`, сборка Linux/Windows.
- Ограничение: CLI-команда `mods import` и контрактный harness — в C07/W03.
- Дальше: C05 — state и `current.txt`.
