# O01 — Systemd/journald adapter

- Сделано: `internal/systemd` с `Runner`, production `ExecRunner`, `Client` (`Show`, `IsActive`, `Logs`, `Control`), unit-константами и `CommandError`.
- `Show` разбирает `systemctl show`; `Logs` вызывает `journalctl -o cat`; `Control` — только `sudo -n` + фиксированный rootctl. Shell не используется.
- Валидация unit и глагола происходит до запуска процесса; `is-active` отличает штатный `inactive` от недоступности systemd.
- Для тестов добавлен `internal/systemd/systemdtest.Runner`: записывает точные argv и отдаёт заготовленный stdout/ошибку.
- Проверено: `gofmt`, `go vet`, `go test ./internal/systemd/...`, `go test ./...`, `go test -race ./...`, `go test ./test/docs`.
- Ограничение: команды `status`/`logs` ещё не подключены к CLI и их JSON-контракт проверяется в O02.
- Дальше: O02 — `status` и `logs` на этом адаптере.
