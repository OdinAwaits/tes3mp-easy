# W03 — `mods import`

- Сделано: `mods import --file <path>` берёт exclusive `flock` (shared для
  `--dry-run`), создаёт `backups/mods`, проверяет regular-file upload и
  совпадение `stat.Dev`, затем один раз потоково валидирует архив и считает
  sha256 сжатого файла.
- Проверено: layout/JSON/CRC/скрипты/лимиты C04, `root-json`, bad CRC, base
  ESM, symlink, duplicate, nested script, traversal и absolute path дают
  `archive_invalid` или `unsafe_path`; upload при ошибке не удаляется.
- При успехе upload переименовывается в `backups/mods/mods-<UTC>.tar.gz` с
  `-01`/`-02`, каталог fsync-ится, `current.txt` не меняется, retention
  применяется сразу и возвращает `pruned`/`warnings`.
- Проверено: `go test ./... -count=1`, `go test -race ./... -count=1`,
  `go vet ./...`, `gofmt`, cross-compile (linux/darwin/freebsd/windows/
  solaris/aix), `git diff --check`.
- Ограничение: `mods import` проверяет один `stat.Dev`, но не делает
  cross-FS копирование; на не-unix платформах проверка устройства явно
  возвращает ошибку, а рабочий target — Linux.
- Дальше: W04 — `mods deploy` (predeploy, staging, restart).
