# C03 — безопасный tar.gz reader

- Сделано: `internal/pathguard` отклоняет абсолютные пути, `..`, NUL, backslash и Windows-drive.
- Сделано: `internal/archive` читает tar.gz потоково, принимает только regular file/directory.
- Symlink, hardlink, device, FIFO, дубликаты, регистровые коллизии и хвостовой мусор отклоняются.
- Лимиты: 512 MiB сжатого, 1 GiB распакованного, 50 000 записей; `Limits` переопределяется в тестах.
- Проверено: `go test`, `go test -race`, `go vet`, `go build`, `gofmt`, `git diff --check`.
- Ограничение: layout mods/state не проверяется — это C04/C05.
- Дальше: C04 — валидация mods-архивов.
