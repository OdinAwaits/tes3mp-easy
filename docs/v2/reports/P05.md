# P05 — Админка и upload

- Сделано: `internal/panel/admin.go`, админские шаблоны и `static/admin.js`; `/admin` показывает статус, health, backup-таймер, doctor и текущие моды.
- Добавлены `/admin/server/{start,stop,restart}`, `/admin/logs`, `/admin/mods` (deploy/rollback/upload), `/admin/state` (create/deploy), `/admin/config/{server,config,banlist}`, `/admin/staff`.
- Upload потоковый: `MaxBytesReader` 512 MiB, `MultipartReader`, UUID в `panel-data/uploads/`, CSRF проверяется в потоке, файл удаляется после `mods import`.
- `state` и `mods` используют `backups list`/`mods deploy`/`state deploy`; конфиги перечитываются через `config get`, `config_invalid` подсвечивает поле; staff читает `players/*.json` только для отображения.
- Добавлены `/api/v1/admin/logs` и `/api/v1/admin/status` для обновления раз в 5 секунд; все POST требуют CSRF, аудит пишется без секретов.
- `doctor` кэшируется на минуту; отчёт со статусом `error` блокирует мутации с `503` и показывает проблемные проверки.
- Проверено: `go test ./... -count=1`, `go test -race ./internal/panel`, `go vet ./...`, `go build ./...`, `gofmt`, `git diff --check`; `admin_test.go` покрывает действия, ошибки, upload, конфиги, staff и анонимный доступ.
- Ограничение: `start`/`stop`/`restart` в ops пока возвращают `internal`; contract-тесты реального бинарника и ACME — дальше (P06).
