# P01 — HTTP-сервер, TLS, конфиг, lifecycle

- Сделано: `cmd/tes3mp-easy-panel` и `internal/panel` с env/flags-конфигом, `--help`/`--version`, кодами 0/1/2 и graceful `SIGINT/SIGTERM`.
- TLS: готовая пара из `panel-data/tls` или self-signed ECDSA P-256 `0600` при отсутствии обоих файлов; неполная/битая пара — ошибка без перезаписи.
- HTTP `:80` отдаёт `308` с сохранением path/query, ACME challenge-path резервирует `404`; HTTPS `:443` — TLS ≥ 1.2, `/healthz` = `ok\n`, CSP и security headers.
- Lifecycle: bind обоих listener-ов до трафика, rollback HTTP при отказе HTTPS, явное закрытие listener-ов даже при отмене до старта `Serve`, shutdown 10 с.
- Проверено: unit/race-тесты панели, полный `go test ./...`, `go vet ./...`, `go build ./...`, ручной smoke на 127.0.0.1:18080/18443 (`308`, HTTP/2 `/healthz`, `SIGTERM` → `stopped`).
- Ограничение: ACME-выпуск по IP не реализован; bind 80/443 проверяется на VM с `CAP_NET_BIND_SERVICE`.
