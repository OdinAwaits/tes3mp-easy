# Отчёты по задачам

Короткие человекочитаемые отчёты для владельца проекта. Они не заменяют план
и контракты, а объясняют простыми словами, что изменилось и что делать дальше.

Правила:

- имя файла — `<ID>.md`, например `C02.md`;
- до 10 строк;
- три вопроса: что сделано, как проверено, что осталось;
- без секретов, токенов и пользовательских данных.
