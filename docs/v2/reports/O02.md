# O02 — `status` и `logs`

- Сделано: CLI-команды `status` (`--unit tes3mp.service|tes3mp-easy-backup.timer`) и `logs --tail N` на `internal/systemd`.
- `Show` теперь передаёт `--timestamp=utc`; `started_at` парсится из `ActiveEnterTimestamp`/`LastTriggerUSec` и отдаётся в RFC3339 UTC, `n/a` → `null`.
- `status`: маппинг failed/activating/active/inactive/unknown и таймера, `health` с учётом `LoadState` и ошибки `is-active`; `LoadState=not-found` и недоступный systemd — exit 6.
- `logs`: обязательный `--tail` 1..10000, точный argv `journalctl`, текст без `--json`, `lines: []` для пустого журнала, недоступный journald — exit 6.
- Обе команды read-only: не берут lock и не читают data root.
- Проверено: `gofmt`, `go vet`, `go test ./...`, `go test -race ./...`, `go test ./test/docs`.
- Ограничение: `doctor` и остальные read-команды ещё не реализованы; O06 добавит полный contract-набор read-команд.
- Дальше: O03 — `doctor` core.
