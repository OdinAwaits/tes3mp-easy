# C02 — JSON-envelope и коды выхода

- Сделано: единый JSON-ответ `{"ok": ...}`, коды выхода 0–10 и `error.code`.
- Сделано: глобальные флаги `--root`, `--json`, `--dry-run`,
  `--lock-timeout`, `--command-timeout`.
- Поведение: `--json` — один объект в stdout, служебный текст только в stderr;
  `--help` печатает обычную справку.
- Проверено: `go test`, `go test -race`, `go vet`, `go build`, ручной запуск.
- Ограничение: команды пока не реализованы и возвращают `internal`.
