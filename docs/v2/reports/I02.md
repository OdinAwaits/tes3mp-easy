# I02 — privilege model

- Сделано: `bootstrap.sh` без `--check` создаёт `tes3mp`/`tes3mp-panel` и их группы, data layout с правами из архитектуры, `rootctl` и sudoers.
- Безопасность: `tes3mp` получает `systemd-journal`, панель — группу `tes3mp`; rootctl принимает только `start/stop/restart` и всегда работает с `tes3mp.service`.
- Sudoers ставится после `visudo -cf`; rootctl ставится `root:tes3mp 0750`, иначе sudo не может выполнить его от `tes3mp`.
- `--check` остаётся read-only; preflight failure не начинает установку; повторный запуск не вызывает `useradd`/`groupadd`.
- Тесты: fake-host для bootstrap, отдельный `rootctl_test.go`; покрыты отказы `systemd-journal`/`visudo`, лишние аргументы и проброс кода systemctl.
- Проверено на Debian 12 x86_64: ownership/modes, `visudo -c`, `tes3mp-panel` → ops от `tes3mp`, `tes3mp` → rootctl; `go test ./...` зелёный.
- Ограничение: `systemctl start` в тестовой среде требует auth (проверен вызов rootctl/sudo); полный bootstrap — I03–I05.
