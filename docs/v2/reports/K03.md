# K03 — Server API и моды

- Сделано: `internal/serverapi` — публичные `GET /api/v1/server` и
  `/api/v1/mods/current`, HTTPS (HTTP только loopback), строгий JSON, лимит
  ответа 1 MiB, три попытки на сеть/5xx, `APIError` и `ErrNoMods`. URL архива
  принимается только на том же хосте и с фиксированным путём; cross-host
  redirect, query, fragment и credentials отклоняются.
- `DownloadMods` пишет потоково через `atomicfile`, проверяет `Content-Length` и
  фактический размер, сообщает прогресс; неверная длина не оставляет файла.
- `internal/mods` проверяет кеш `cache/<name>` по размеру и SHA256, прогоняет
  tar.gz через общий `internal/archive`, распаковывает в
  `servers/<id>/.staging/`, сверяет базовые ESM по CRC из
  `requiredDataFiles.json`, копирует только `plugins/` в `data/Data Files` и
  перегенерирует `openmw.cfg` с сохранением пользовательских строк.
- `Data Files` и `openmw.cfg` меняются через `*.old`, digest `.mods-sha256`
  пишется последним; ошибка возвращает прежнюю установку. Совпадение digest
  пропускает скачивание; старые `*.old` и staging восстанавливаются/удаляются
  при следующем запуске.
- `internal/app` получил `CheckServer`, `ModsState`, `UpdateMods`; в Fyne
  добавлены кнопки «Проверить сервер» и «Обновить моды» с диалогом прогресса.
  Русские строки добавлены, паритет ключей сохранён.
- Проверено: `go test ./... -count=1`, `go test -race ./... -count=1`,
  `go vet ./...`, `go test ./test/docs`, `gofmt -l`, `go build ./...`,
  `git diff --check`.
- Ограничение: реальный сервер с модами и GUI smoke на Windows/Linux не
  запускались — это K06/E2E; отмена скачивания и полный мастер — K05.
