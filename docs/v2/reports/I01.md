# I01 — preflight bootstrap

- Сделано: корневой `bootstrap.sh` с read-only preflight; `--check` и `--root`.
- Проверяет: root, Debian 12+/Ubuntu 24.04+, x86_64, systemd PID 1/`systemctl`, RAM, swap, общий размер и свободное место диска.
- Все отказы собираются и выводятся вместе; ниже 640 MiB RAM — предупреждение, ниже порогов RAM/swap/диска — ошибка.
- Идемпотентность: скрипт не пишет на диск; тест сравнивает дерево файлов до и после двух запусков.
- Тесты: `test/infra` — реальный `bootstrap.sh` с fake `/etc/os-release`, `/proc`, systemd, `id`, `uname`, `df`, `systemctl`; успех, warning, пороги и каждый отказ.
- Проверено: `go test ./test/infra`, `go test ./...`, `go test -race ./...`, `go vet ./...`, `gofmt -l .`, `bash -n bootstrap.sh`.
- Ограничение: установочные стадии (пользователи, systemd, runtime, базовые моды) — I02–I05; сейчас скрипт явно сообщает, что они не реализованы.
- Дальше: I02 — пользователи, каталоги, sudoers, rootctl.
