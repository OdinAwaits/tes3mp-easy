# O05 — `backups list`

- Сделано: `backups list --type mods|state [--limit] [--before] [--sha256]` с
  `current`, `next_before`, сортировкой mtime/имя и UTC-RFC3339.
- `mods` включает `mods-*`/`mods-init-*`, `state` — все state-классы; symlink и
  имена вне §6.6 игнорируются. Битый `current.txt` — exit 7.
- `--before` безопасен (`unsafe_path`, exit 8), типизирован (exit 2) и работает
  после удаления курсора retention; `--sha256` — только текущая страница.
- Проверено: `gofmt`, `go vet ./...`, `go test ./... -count=1`,
  `go test -race ./... -count=1`; contract-тесты реального бинарника, включая
  2016 архивов, пустой каталог и точные ключи JSON.
- Ограничение: `backups create` остаётся W02, lock/запись в O05 не входят.
- Дальше: O06 — полный contract-набор read-команд.
