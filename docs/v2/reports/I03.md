# I03 — systemd units, journald, sysctl

- Сделано: `systemd/tes3mp.service`, `tes3mp-panel.service`, `tes3mp-easy-backup.service`, `tes3mp-easy-backup.timer`; journald drop-in с `SystemMaxUse=100M`/`RuntimeMaxUse=32M`; `sysctl.d/99-tes3mp-easy.conf` с `vm.swappiness=10`.
- Bootstrap ставит файлы `0644 root:root`, валидирует units через `systemd-analyze verify` до записи, делает `daemon-reload`, перезапускает journald и применяет `sysctl -p`. Повторный запуск идемпотентен.
- Runtime ещё нет, поэтому verify допускает только `Command ... is not executable: No such file or directory` для ожидаемого `ExecStart`; опечатки в пути, синтаксические и dependency-ошибки остаются фатальными. Юниты не запускаются в I03 — первый запуск в I05.
- Лимиты: сервер 384M/448M, `OOMScoreAdjust=-500`, запись только в `players/` и `world/`; панель 48M/64M, `CAP_NET_BIND_SERVICE`, `NoNewPrivileges=no`; backup 48M/64M, `Nice=19`, `IOSchedulingClass=idle`, `Type=oneshot`, `TimeoutStartSec=9min`.
- Тесты: fake-host bootstrap (установка, режимы, порядок verify/install, команды systemd/sysctl, ошибки, идемпотентность) и `test/infra/systemd_test.go` (содержимое units/timer/drop-in).
- Real-host smoke на Debian 12 x86_64: bootstrap прошёл, `systemd-analyze verify` принял три ожидаемых отсутствующих `ExecStart`, файлы `0644 root:root`, `systemctl daemon-reload` и restart journald прошли, `vm.swappiness=10`, повторный запуск не изменил содержимое; юниты остались `inactive`.
- Ограничение: production-пути units фиксированы (`/tes3mp-easy`, `/opt/tes3mp-easy`); `--root` меняет только data layout.
