# TES3MP Easy

TES3MP Easy — сервер Morrowind-мультиплеера (TES3MP 0.8.1) и desktop-клиент с
автоматической синхронизацией модов и регулярными бэкапами мира. Админ ставит
сервер из релизного архива, а игрок указывает папку Morrowind и адрес сервера —
дальше клиент сам скачивает нужные моды.

## Установка сервера

**Требования:** Debian 12+/Ubuntu 24.04+ x86_64, 1 vCPU, 512 MiB RAM, 7 GiB
диска, открытые порты `25565/udp`, `80/tcp`, `443/tcp` и пользователь с
`sudo`. Замените `0.1.0` на актуальную версию из
[GitHub Releases](https://github.com/Saagilat/tes3mp-easy/releases).

```bash
sudo apt-get update && sudo apt-get install -y curl ca-certificates && VERSION=0.1.0 && A="tes3mp-easy-${VERSION}-linux-amd64.tar.gz" && B="https://github.com/Saagilat/tes3mp-easy/releases/download/v${VERSION}" && curl -fsSLO "$B/$A" && curl -fsSLO "$B/$A.sha256" && sha256sum -c "$A.sha256" && tar -xzf "$A" && sudo "./${A%.tar.gz}/bootstrap.sh"
```

`bootstrap.sh` ставит TES3MP, оба бинарника, systemd-юниты, пользователей и
каталоги, после чего запускает игру, таймер бэкапов и панель.

### Первый вход

```bash
sudo cat /tes3mp-easy/panel-data/initial-password.txt
```

Откройте `https://<IP-сервера>/`, войдите временным паролем и сразу смените
его. При первом входе подтвердите самоподписанный сертификат в браузере.

В панели откройте **Настройки** и задайте:

- **Имя сервера** — то, что увидят игроки;
- **Пароль сервера** — пароль для входа в игру; пароль панели настраивается
  отдельно.

После сохранения нажмите **Перезапустить** на **Обзоре** или выполните
`sudo systemctl restart tes3mp`, чтобы новые настройки применились.

Панель работает по HTTPS. Чтобы клиенты доверяли её сертификату, используйте
доверенный сертификат в `panel-data/tls/` или добавьте `cert.pem` в доверенные
корни ОС на компьютерах игроков. Подробнее — в
[runbook](docs/v2/08-runbook.md#2-установка).

Скопируйте `cert.pem` с сервера. На Linux:

```bash
sudo cp cert.pem /usr/local/share/ca-certificates/tes3mp-easy.crt
sudo update-ca-certificates
```

На Windows: откройте `certmgr.msc` → **Доверенные корневые центры
сертификации** → **Импорт** → выберите `cert.pem`.

### Настройка модов

Сервер стартует с базовым мод-паком. Чтобы добавить свои моды, откройте
**Моды**, загрузите `.tar.gz` и нажмите **Deploy** у нужного архива. Панель
обновит `sha256` и перезапустит сервер, если он запущен. Клиенты при следующем
запуске скачают и установят новую версию мод-пака. Формат архива описан в
[runbook](docs/v2/08-runbook.md#6-моды).

### Проверка

```bash
sudo systemctl status tes3mp.service --no-pager
sudo systemctl status tes3mp-easy-backup.timer --no-pager
sudo systemctl status tes3mp-panel.service --no-pager

sudo -u tes3mp /opt/tes3mp-easy/bin/tes3mp-easy-ops \
  --root /tes3mp-easy --json doctor
```

Ожидаемо: игра и панель `active (running)`, таймер `active (waiting)`,
`doctor` завершится успешно.

### Данные для игроков

```text
Адрес:  <IP-сервера>
Порт:   25565
Пароль: <пароль сервера из панели>
Панель: https://<IP-сервера>/
```

## Установка клиента

### 1. Скачайте клиент

Возьмите клиент из [GitHub Releases](https://github.com/Saagilat/tes3mp-easy/releases):

- **Windows 10/11:** `tes3mp-easy-client-<version>-windows-amd64.zip` —
  распакуйте и запустите `tes3mp-easy-client.exe`.
- **Linux:** `tes3mp-easy-client-<version>-linux-amd64.tar.gz` — распакуйте и
  запустите `./tes3mp-easy-client`. Понадобятся Steam + Proton, Morrowind и
  графические библиотеки X11/OpenGL (Fyne).

### 2. Пройдите первичную настройку

При первом запуске клиент откроет мастер:

1. Выберите язык.
2. Укажите папку Morrowind — ту, внутри которой лежит `Data Files/` с
   `Morrowind.esm`, `Tribunal.esm` и `Bloodmoon.esm`.
3. Оставьте рабочую папку по умолчанию или выберите свою.
4. Дождитесь установки TES3MP и шрифтов.
5. Нажмите **Готово**.

Клиент использует папку Morrowind как источник данных, а моды и локализацию
хранит в отдельном профиле.

### 3. Добавьте сервер и играйте

На главном экране нажмите **Добавить** и заполните:

| Поле | Значение |
|---|---|
| Название | любое, например `Друзья` |
| Адрес | IP сервера |
| Порт | `25565` |
| Пароль | пароль сервера от админа |
| URL панели | `https://<IP-сервера>` |

Затем:

1. **Проверить сервер** — клиент покажет статус и текущий мод-пак.
2. **Обновить моды** — скачает и проверит архив модов с панели.
3. **Играть** — клиент подготовит `openmw.cfg` и запустит TES3MP.

При следующих запусках достаточно нажать **Играть**: клиент сверит мод-пак с
сервером и при новой версии автоматически скачает и установит обновление.

## Обновление

Сервер обновляется тем же архивом: скачайте новую версию, проверьте sha256,
распакуйте и снова выполните `sudo ./bootstrap.sh`. Данные в `/tes3mp-easy`,
конфиги и state сохраняются. Перед обновлением можно сделать бэкап в панели.

Клиент обновляется заменой бинарника/архива. Настройки и профили серверов
остаются в `%APPDATA%\tes3mp-easy` (Windows) или
`~/.config/tes3mp-easy` (Linux).
